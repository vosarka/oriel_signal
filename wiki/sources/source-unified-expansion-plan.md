## Executive Vision (Unified)

Oriel Signal is a cinematic AI-guided symbolic self-discovery platform that translates personal resonance data into a precise Static Signature (codon map), actionable micro-corrections, ORIEL interpretation, Field Journal practice, and the Vossari Archive — all embodied through an archive-grade 64-codon emblem system (the Codex).

**Core promise:** “You are not broken. You are noisy. This platform helps you hear your own signal.”

**Non-negotiable sequencing:** Practical value → personal result → symbolic meaning → deep lore. Never the reverse.

### 1. Positioning & Anti-Confusion (Plan1 — launch-critical)

- Public language hierarchy: Oriel Signal (product) → Static Signature / Personal Codex (core deliverable) → ORIEL (guide) → deeper Vossari / Conduit Hub / Archive (revealed after first result).

### 2. Business & Launch Model (Plan1)

- First revenue: Free Static Signature preview → paid Full Static Signature Report / Personal Codex (€19–€39).

- Premium: Codex bundle (€49–111) with full report, sigil cards, later artifacts.
- Audience: AI-spiritual seekers, Human Design/astrology users, creatives, burned-out seekers.
- Avoid at launch: NFT-first language, heavy crypto, marketplace, complex lore before personal results.
